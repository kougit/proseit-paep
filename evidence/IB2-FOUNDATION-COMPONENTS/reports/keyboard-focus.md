# IB2-FOUNDATION-COMPONENTS — Keyboard and Focus (IB2-AC08; IR-01 §6.4 overlay/navigation concerns)

Measured on the final code commit (`logs/verification-6dc71cc/`) on 2026-09-27. Keyboard model: the specimen metadata `keyboard` lines, checked against the key handling in the component source (`keydown` handlers, `.focus()` calls, `showModal()`, `popover`, `tabindex`). Proof: the `it('…')` titles in `packages/components/src/lib/<id>/<id>.spec.ts`, quoted exactly. The tests run in Chromium through `npm run test:components` (Vitest browser mode); this report does not re-run them. Status: CANDIDATE evidence map.

Focus terms: **entry** = where focus goes when the component opens or activates; **trap** = focus contained; **restore** = where focus returns; **roving** = one tab stop with arrow-key movement.

| Component | Keyboard model | Focus behaviour as implemented | Proving tests |
| --- | --- | --- | --- |

| drawer | Tab/Shift+Tab contained; Escape closes (suppressed while busy) | Extends `PaepModalBase` (same modal `<dialog>`). **Entry:** title, or first field for a form. **Trap:** native modal. **Restore:** invoker | "opens as a modal dialog named by its title and focuses the title"; "focuses the first field on entry when the drawer holds a form"; "contains Tab, closes on Escape and returns focus to the invoker"; "ignores Escape and Cancel while busy"; "closes from a paepDialogClose control" |

## 2. Navigation and composite widgets

| Component | Keyboard model | Focus behaviour as implemented | Proving tests |
| --- | --- | --- | --- |
| tabs | Tab enters on the selected tab, then the panel; ArrowLeft/ArrowRight previous/next (mirrored in RTL, wrapping); Home/End; automatic (arrows select) or manual (Enter/Space select) | **Roving** tabindex on `role="tab"` buttons. | pagination | Tab between Previous, numbers, Next; Enter (and Space on buttons) activates | **Restore/redirect:** after a page change focus moves to the paged region heading (`focusTarget`). | table | Tab reaches links, Details buttons and actions only; Enter/Space on Details toggles the row detail; scroll fallback region is a tab stop scrolled by arrows | Focus stays on Details. | list | Tab reaches links and item actions only; Enter/Space activates | State changes announced politely without moving focus; after Retry focus moves to the heading | "reaches only links and actions with Tab and runs item actions from the keyboard"; "shows the empty state (with action) and announces it without moving focus"; "shows an error alert with Retry; after reload focus moves to the heading" |
