Structure

Structure family: restrained primitives with token-only styling.

Card

Record summary

Default card: title and body.

Stock position for the current reporting period across all sites

Two-line title wraps; actions wrap below under 30 rem.

Body content grows with its content. Cards are not click targets in IB2.

Purpose
Group a self-contained unit of related content (e.g. a summary) within a page or grid.
Variants
Default (level 1). Raised (level 2) is DEFINED as a token but NOT used by any IB2 component: no controlled use case justifies it yet.
States
default, with header, with actions, long title, long content, focus-visible, narrow-width. Not applicable: hover, disabled, selected, read-only, invalid
Keyboard
None of its own.
Accessibility
Landmark-free grouping with heading structure. <section> with aria-labelledby when it has a title, or <article> for standalone items; heading level configurable.
Responsive
Container query for header layout.
Localisation / RTL
Header actions at inline-end (left). Long content: Proven.
Usage guidance
Do not: Whole-card click targets; decorative shadows; nesting cards in cards.
Evidence
EVIDENCE-LINK-PENDING: unit · accessibility · visual · 320px (IB2 implementation)

Panel

Delivery details

Static panel with header actions.

Contains 2 errors

Hidden content

Purpose
Divide a page into titled sections, optionally collapsible for progressive disclosure of long forms (PAEP §6.2).
Variants
Static · Collapsible (justified by PAEP §6.2 progressive disclosure; default expanded; state is not persisted by the component).
States
default, collapsed, with actions, long title, long content, hover, focus-visible, invalid, narrow-width. Not applicable: disabled, selected, read-only
Keyboard
Collapsible: Enter/Space on the toggle.
Accessibility
Disclosure pattern. <section aria-labelledby>; collapsible: heading containing <button aria-expanded aria-controls>; collapsed body uses hidden.
Responsive
As Card.
Localisation / RTL
Chevron rotation mirrors. Long content: Proven.
Usage guidance
Do not: Accordion-style mutually exclusive panels (not in IB2); collapsing required errors out of sight without a header message.
Evidence
EVIDENCE-LINK-PENDING: unit · accessibility · visual · 320px (IB2 implementation)

Purpose
Separate groups of content when spacing alone is insufficient.
Variants
horizontal (full, inset) · vertical.
States
default, narrow-width. Not applicable: hover, focus-visible, disabled, loading, long-label, selected, read-only, invalid
Keyboard
None.
Accessibility
Decorative contrast exempt. Horizontal: <hr> (thematic break) or aria-hidden when purely visual; vertical: role="separator" aria-orientation="vertical" only when it separates groups meaningfully, otherwise aria-hidden.
Responsive
See narrow.
Localisation / RTL
Logical margins. Long content: Not applicable
Usage guidance
Do not: Using dividers to fake table rows; heavy or coloured dividers.
