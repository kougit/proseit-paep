## 3. References used

Public standards were used as **behaviour specifications only**:

- WCAG 2.2;
- the WAI-ARIA Authoring Practices patterns: disclosure, menu button, combobox with listbox, dialog (modal), and landmarks.

Generic conventions were used as described in words, not as visuals: a sidebar with collapsible groups, a topbar, a command palette, a status banner and a mobile navigation sheet. **No** screenshot, source, theme, icon or layout of any product was viewed or used.

Prohibited inputs (DWP §19) were **not used**:

- Ultima;
- PrimeNG, PrimeFlex and PrimeIcons, and PrimeNG template layouts;
- SAP Fiori / UI5;
- Angular Material themes and icons;
- commercial admin templates and UI kits;
- Frappe Desk, ERPNext and frappe-ui visual design;
- vendor or competitor shell screenshots;
- customer or real tenant/user data.

## 4. Independent-composition statement

The shell layout, the region arrangement, the 24 shell icons, the placeholder mark, the reference CSS (`shell.css`) and every screen were composed in this design stage from the DWP requirements and the accepted PAEP tokens. The generator scripts were written from scratch for HOF-IB3-001. The only reused material is PAEP's own accepted HOF-IB2-001 v1.1 files listed in §2, used unchanged. All sample data is synthetic (DWP §12). The Arabic and Hebrew strings are design fixtures, valid for mechanical RTL qualification (X-04); native-copy review is pending and required before IB3 acceptance.

## 5. Assets

See `assets/asset-register.md`: 24 icons and 1 placeholder mark, all `authored-in-HOF-IB3-001`, ProSEIT-owned. There are no web fonts (system font stack per OD-01) and no CDN or third-party assets.

## 5a. Content credentials

The project file store adds Anthropic content-credential (C2PA) metadata to SVG and PNG files a few seconds after they are written. It records that Claude provided the file; it is not design content. The manifest hashes files as stored, after that metadata has settled, and records for each SVG asset an `authoredSha256` with the metadata removed.
