# IB3-ENTERPRISE-SHELL — Acceptance Criteria

All criteria are mandatory. They are the IB3 pre-flight acceptance-criteria draft (`14`, AC-IB3-01..27) adopted with the PO/SA implementation authorisation of 2026-10-06, with the final design decisions applied. No criterion may be deleted, weakened, bypassed or rewritten to obtain PASS. PASS is technical; ACCEPTED is the PO/SA's decision. AC-IB3-27 is not a Claude criterion.

| ID | Area | Criterion | Verification |
| --- | --- | --- | --- |
| AC-IB3-01 | Package boundaries | Enterprise lives in `packages/enterprise`; every PAEP package is imported only through its single public entry point; no secondary entry point; enterprise depends only on permitted packages; apps compose it; shared state limited to signals/RxJS, no store framework, immutable RuntimeConfigStore, standalone and zoneless-compatible | `qa:architecture`; `qa:enterprise` milestone-scope and import rules; seeded negatives (enterprise → frappe-sdk / analytics / domain-* / offline; app → frappe-sdk; deep import) |
| AC-IB3-02 | HOF conformance | Implementation conforms to HOF-IB3-001 v1.0 (manifest `645dd2e9…fce5`); every material difference is a DDR-IB3-* with PO/SA disposition | `evidence/design-handoff/HOF-IB3-001/conformance-report.md` (HOF element → symbol → test/evidence → result) |
| AC-IB3-03 | Capability coverage | Shell areas A-H implemented; J limited to session-only shell preferences; I limited to the generic workspace/page-frame regions | `TRACEABILITY.csv`: every REQ-IB3-* row names concrete evidence |
| AC-IB3-04 | Reuse / no duplication | No generic primitive duplicated or privately substituted in enterprise or apps; generic primitives only in components, generic icons only in foundation, as approved; shell menus share one governed positioning/menu base; no `popover="manual"` in enterprise | `qa:enterprise` duplication rules + negatives; S03/S07 census = approved list exactly; enterprise public-API census |
| AC-IB3-05 | Responsive / 320 px | No page-wide horizontal scroll at 1440 / 1024 / 834 / 640 / 375 / 320 / 320×256; never-hidden set present and in viewport at 320 and 320×256; navigation transitions per HOF | `qa:shell` overflow, off-screen and target-size checks + negatives |
